# InsightFlow

AI-Powered Business Analytics SaaS

InsightFlow allows businesses to upload Excel or CSV datasets and analyze them using AI.

## Features

- Authentication
- Excel & CSV Upload
- AI Business Chat
- Interactive Dashboard
- KPI Analytics
- Charts
- Executive Reports
- Data Cleaning
- Dataset Management

## Tech Stack

Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

Backend
- Node.js
- Express
- MongoDB Atlas

AI
- OpenAI API
